# Security policy

## Supported version

Security fixes are applied to the current 1.x release line. Older development
snapshots are not supported.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could put users, projects,
or systems at risk. Email `info@lanesaudio.com` with:

- a concise description and impact;
- affected version and host/operating system;
- reproduction steps or a proof of concept;
- any suggested mitigation;
- whether and when you plan to disclose the issue publicly.

You should receive an acknowledgement within seven calendar days. Lanes Audio
will coordinate validation, remediation, and disclosure with the reporter.

Ordinary crashes, audio defects, and accessibility regressions can use the
public issue tracker unless they expose data or cross a security boundary.
